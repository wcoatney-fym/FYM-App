Ghost minimums are the floor goals you set for each tenure tier. Agents never see these numbers — when they set a personal goal below the floor, their Manager is notified and routes the request as an exception (with your override authority). This protects against demotivating an agent by anchoring them to the floor, while ensuring the agency floor is enforced. Setting these is Agency-Owner-only.
