GHL Workflow Blueprint — At-Risk Pipeline Sync

Two workflows per agency sub-account. Build these in GoHighLevel Workflow Builder.

Setup Checklist (per agency sub-account)

1. Create pipeline "At-Risk Pipeline" with 8 stages: New, Responded, Manager, Agent, Code Red, Pending, Saved, Lost

2. Build Workflow 1 (Suppression Tag Lifecycle) — trigger on tag add, wait 5 min, remove tag

3. Build Workflow 2 (Stage Change Webhook) — trigger on pipeline stage change, check tag, send webhook

4. In FYM App: go to CRM Ops → agency → GHL tab → enter API key + location ID → test connection

5. Flip the ghl_api_enabled toggle → one-time seed pushes app pipeline state to GHL

6. Done — stage changes now flow both directions in real-time
